# Soroban

## Español

Soroban es un proyecto diseñado para ayudar a entender y enseñar la forma de contar en japonés.

Para el uso de esta herramienta, es necesario que los alumnos ya sepan contar hasta el 10 en japonés, soroban solo es una ayuda visual del ábaco y una guia de qué pronunciar después de cada número

El proyecto se basa en la siguiente referencia:
- [referencia](https://www.rightlobemath.com/digitalabacus/abacus_rebuild.html)

### ¿Qué incluye?
- Lecturas en Romaji
- Lecturas en Hiragana
- Lecturas en Kanji

Esto permite usar la aplicación para ejercicios en clase y reforzar el aprendizaje de los números japoneses.

## English

Soroban is a project created to help understand and teach the way of counting in Japanese.

For the use of this tool, it is necessary that students already know how to count to 10 in Japanese; soroban is only a visual aid for the abacus and a guide to what to pronounce after each number.

The project is based on the following reference:
- [reference](https://www.rightlobemath.com/digitalabacus/abacus_rebuild.html)

### What does it include?
- Romaji readings
- Hiragana readings
- Kanji readings

This makes the application useful for classroom exercises and helps reinforce Japanese number learning.

- Open the app here:
  - https://danieruhuli.github.io/soroban/Soroban.html

### Changelog
